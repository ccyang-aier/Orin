## 二、四个维度的具体审查

### 1️⃣ 新概念出现太突然

#### 问题位置与表现

**问题 1a：第1.3节突然给出数学公式**
- 第1.1-1.2建立了直觉（软寻址、硬寻址对比）
- 第1.3直接跳到："在现代 Transformer 语境中，Attention 通常指 Scaled Dot-Product Attention"
- 读者还未理解**为什么**要这个特定形式，就被公式砸到

**改进方案**：
```
删除第1.3的说明文字，改为：
"这个软寻址的直觉，在Transformer中被固化成了一个具体的数学形式..."
增加过渡段落解释：
- Query与Key如何转化为可微的相关度打分
- 为何用点积（最后会回答）
- 为何需要归一化（接第3章详述）
```

**问题 1b：第2.3的Cross-Attention突兀**
- 前面全是Self-Attention的例子
- 突然说"但如果当前要生成的内容，需要从另一段已经编码好的文本里取信息呢？"
- 读者可能困惑：这是什么场景？为什么现在讲？与Self-Attention的关系是什么？

**改进方案**：
```
补充承转句：
"前面讨论的都是Self-Attention，即当前序列内部的信息流动。
但Transformer还支持另一种模式：来自不同序列或模块的信息查询..."
```

**问题 1c：第5.4的MQA/GQA出现无序幕**
- 第5.3还在讲维度如何分配
- 第5.4突然转向推理效率、KV cache这个完全新的维度
- 读者从"多头在训练时怎样学"跳到"推理时怎样存储"

**改进方案**：已修改
```
增加明确的过渡：
"训练阶段，多头的主要考量是表达能力和计算效率。
但进入推理阶段后，一个新的瓶颈浮现出来：..." ✅
```

### 2️⃣ 结论先于推导

#### 问题位置与表现

**问题 2a：第1.1的结论太突兀**
- 开篇先讲"Attention = 可微分的软寻址"
- 然后才用代词消解的例子论证
- 读者没有被充分说服为何要这个定义

**原文顺序**：
```
1. 定义：Attention = 软寻址
2. 解释为什么需要
3. 具体例子
```

**改进方案**：
```
✅ 已修改：先从上一篇的瓶颈入手
1. 回顾：早期序列模型把所有历史压进固定向量的问题
2. 新想法：直接访问上下文
3. 实现机制：软寻址
4. 定义：Attention = 可微分的软寻址
```

**问题 2b：第3.2的√d_k缩放突兀**
- 直接给出方差分析
- 未说明：为何要稳定方差？softmax饱和的后果是什么？

**改进方案**（第3.2已修改方向，但可进一步优化）：
```
补充推导前的动机：
"点积作为相关度评分，有一个隐藏的数值陷阱...
当维度增大时会发生什么？"
→ 然后展示方差分析
→ 然后解释softmax饱和的梯度后果
```

**问题 2c：第4.4的mask与架构分化**
- 结论："mask决定了模型的信息边界，因此它本质上是架构语义的一部分"
- 但读者此时还没看过Transformer的三种架构（那是第04篇）
- 结论先出现，推导留到下一篇

**改进方案**：✅ 已修改
```
不说"是理解架构分化的关键入口"
改为：
"Encoder-Only（如BERT）用双向Attention，Decoder-Only（如GPT）
用causal mask，Encoder-Decoder两者兼有——mask是区分这三种
架构形态的关键变量之一。"
这样既指出事实，又避免留悬念
```

### 3️⃣ 部分句子像在解释"为什么本文这样写"

```

```

**问题 3b：第2.1**

```
"初学者常问：既然输入token已经有embedding，为什么还要投影成Q、K、V三套向量？"
```
- 开头的"初学者常问"是在解释为什么要讲这个问题
- 读者不需要这个元层注解

**改进方案**：✅ 已修改方向
```
直接进入问题：
"一个位置在Attention中扮演了三种不同角色..."
无需"初学者常问"这类框架说明
```

**问题 3c：第2.2**
```
"假设模型正在翻译：..." "这就是Attention与传统对齐的区别"
```
- 末尾的"这就是..."在强调这个例子的目的
- 读者已经理解，无需强调

**改进方案**：
```
例子后直接转到下一个问题，
不需要"这就是...的区别"这类总结性陈述

```

**问题 3d：第3.1**

- "关键是"在强调为什么这样讲

**改进方案**：


**问题 3e：第5.2**
```
"图里把head标成'语法''指代''局部''远距'，是教学上的直觉标签，
不表示真实模型中每个head都会稳定对应一个人类可命名功能。"
```

- 这是在为自己的教学设计解释
