01
Panorama

全景拓扑：模型到卡端自动映射。

用户场景大模型业务上线后，客户需要快速确认模型、实例、节点和加速卡是否匹配；传统平台里这些信息分散在不同页面，资源关系只能人工拼接。

所见即所得把服务入口、实例承载、节点归属与加速卡状态收敛到同一张关系视图。请求数、Token、TTFT、TPOT 与加速特性状态可以沿链路逐级下钻，页面呈现的是模型服务真实运行链路。

02
Fault propagation

故障传播：卡端异常直达服务影响。

用户场景生产环境出现驱动异常、显存溢出或温度过高时，服务质量已经受损，但问题源头常常藏在硬件或子系统监控里，定位耗时且容易遗漏。

所见即所得把卡端异常向上关联到实例和模型层，父级自动呈现最高严重级别。影响实例、风险等级、异常来源与服务状态保持同屏可读，客户能快速判断是否导致服务降级。

03
Performance trace

性能追踪：延迟波动可以沿链路解释。

用户场景当首字延迟、生成延迟或 Token 吞吐出现波动时，客户需要判断问题来自模型侧、实例调度、节点资源，还是加速卡瓶颈。

所见即所得把 TTFT、TPOT、Tokens 吞吐、利用率、显存水位、温度和功耗放到同一时间窗口。性能变化可以沿拓扑定位到实例、节点或加速卡层，用于对比单卡瓶颈、多实例负载不均或 PD 分离调度异常。

04
Acceleration value

收益量化：加速能力转化为业务数字。

用户场景客户知道 KVCache 卸载、推测解码已经开启，却很难判断这些能力是否真正作用在当前业务上，收益是否稳定、是否可量化。

所见即所得展示 HBM、DRAM、NVMe 的卸载分布、KVCache 命中率、节省计算总 Token 数、草稿模型接受率与接收总 Token 数，把加速能力转化为可验证、可复盘、可汇报的收益结果。
